Zuna: two recordings,
the complete analysis history

Completed comparisons, preparation audits, aggregate data and unfavorable findings. Original recordings remain private. Nothing is uploaded automatically.

Different outcomes, limited claims. Corrected Run 1 favored interpolation overall; Run 2 favored Zuna against that baseline. These are not independent-participant validation or proof of EEG cleaning. Run 2 optical timing remains unverified. Read the limitations before interpreting either result.
