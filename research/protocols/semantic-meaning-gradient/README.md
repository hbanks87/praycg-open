# Semantic Meaning Gradient

Semantic Meaning Gradient (SMG) v1.0 is a separate protocol family in the master document. It compares coherent low-meaning material, high-meaning narrative material, and analytic override. Its indices and thresholds are described there as unvalidated candidates for protocol development.
