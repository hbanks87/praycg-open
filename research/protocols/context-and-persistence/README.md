# Context and persistence pilot

This study asks whether the order of preceding narrative context changes later understanding of a shared ending, and whether measured responses persist after the stimulus stops. Its current status is a **development pilot with no human outcomes**.

Each viewer receives one first exposure: either coherent or disrupted context, followed by the same ending. The delayed visit targets the next day and places novel reasoning scenarios before explicit questions about the excerpt. Understanding, near transfer, far transfer and literal recall remain separate outcomes.

The local CETR pilot was built around a *Contact* excerpt. This public companion provides the design, a general scoring framework and synthetic examples. It contains no film, film stills, soundtrack, transcript, actual study questions/keys, participant responses, allocation ledger or recorded physiology. A researcher using different rights-cleared material must freeze a new study version and new content-specific measures.

Matching the ending file controls digital content, not the viewer's preceding state or physical playback. Persistence may reflect arousal, recovery or memory as well as other processes. These draft measures and synthetic checks do not establish a meaning-specific signal or generalization across films.
