# PRAYCG Framework NUPI Update v0.5

This update adds NUPI_v0.1 - Narrative Update Polarity Index - to the PRAYCG/Topo-OSM framework.

NUPI formalizes the distinction between:

- accommodative-load narratives, where meaning requires model expansion, high semantic work, or destabilizing update;
- resolutive-recovery narratives, where meaning closes an unresolved loop and is followed by regulatory recovery;
- high-load-with-recovery narratives, where strong semantic perturbation is followed by strong reflective/regulatory recovery;
- polarity-unresolved runs, where a final reflective baseline or sufficient after-state physiology is unavailable.

## Primary formula

```text
ALI = mean(semantic intensity, Target specificity, complexity perturbation, TTI, primary endpoint pass score)
RDI = mean(Baseline2 regulation, Baseline2 semantic echo, EET afterstate echo, self-report echo)
NUPI = RDI - ALI
```

## Claim boundary

NUPI does not measure literal thermodynamic heat, ATP, glucose, oxygen consumption, clinical restoration, consciousness, or moral value. It is a proxy-level profile classifier that sits below A-MRED in the endpoint hierarchy.
