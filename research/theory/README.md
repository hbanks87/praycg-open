# Theory and its development

The PRAYCG theory record contains hypotheses, proposed mechanisms, operational definitions, and revisions over time. This index preserves those distinctions and directs readers to the original documents.

[Research entrance](../README.md) · [Measures](../measures/README.md) · [Protocols](../protocols/README.md)

## Reading order

1. Read [what this is and is not](../ethics-and-claim-boundaries/originals/what_this_is_and_is_not.md).
2. Use [foundations](foundations/README.md) for the master theory and protocol documents.
3. Follow [extensions](extensions/README.md) into versioned theoretical and operational developments.
4. Compare [historical versions](historical-versions/README.md) when tracing changes in terminology, assumptions, or scope.

Versions identify documents, not a level of scientific validation. Markdown, PDF, and Word files are listed as available formats; this index does not certify that different formats contain identical text.
