# What this is and is not

## What this is

PRAYCG is an exploratory open-source protocol and analysis pipeline for naturalistic narrative psychophysiology. It is designed to compare:

1. **Phase-scrambled control** — same source material with recognizable story disrupted.
2. **Target** — intact narrative watched naturally.
3. **Contextual Override** — the same intact narrative under analytic task demand.

## What this is not

It is not a proof of consciousness, memory biology, microtubules, biophotons, quantum biology, souls, or metaphysics. It is not a clinical or diagnostic tool.

## Working scientific question

When a story is allowed to matter, does the body-brain system show a measurable state trajectory beyond light, sound, motion, cue timing, task effort, and artifact?
