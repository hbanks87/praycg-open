# Contributing

Contributions are welcome, especially critiques that make the protocol more falsifiable.

Priority contribution areas:

- EOG/EMG artifact controls.
- OpenBCI acquisition reliability.
- LSL timing and event-marker strategy.
- Safer stimulus and control generation.
- Media-level exogenous regressor extraction.
- Simplifying the suite toward a cleaner A-MRED endpoint.
- Unit tests and synthetic negative controls.

Please preserve claim boundaries. Do not submit language claiming that PRAYCG proves consciousness, memory biology, quantum biology, or metaphysical conclusions.
