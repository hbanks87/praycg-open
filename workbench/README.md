# Use the PRAYCG Workbench

## Get the current public version

Download **PRAYCG_Workbench_Public_Alpha_11_13_1.zip** from the [Public Alpha 11.13.1 release](https://github.com/hbanks87/praycg-open/releases/tag/PRAYCG_Workbench_Public_A11.13.1). Follow the [installation guide](docs/installation.md) to verify the download, extract it and start Control Center. Run `CREATE_SYNTHETIC_EXAMPLE.bat` to try Analysis Forge. Its Results view shows each method, source and usable support.
