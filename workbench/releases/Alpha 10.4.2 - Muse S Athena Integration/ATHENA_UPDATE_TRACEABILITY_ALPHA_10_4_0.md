# Alpha 10.4.0 — requested Athena updates

These records describe implemented software behavior. They do not certify hardware or scientific endpoints. Validation results belong to the generated build report, not to this checklist.

| Request | Implementation | Remaining evidence |
|---|---|---|
| 1. Compatibility for every protocol | 91 versioned profiles; actual measured-site, channel-count, rate, sensor and timing requirements; separate task/endpoint/analysis states; Atlas preview and session checks. | Run-specific signal quality and the declared endpoint's prerequisites. |

| 7. Optional EEG in behavioral tasks | The 13 behavioral protocols keep their response outcomes and optional EEG; descriptive EEG quality does not rewrite behavior. | Any new EEG contrast needs its own declared analysis. |
| 8. Core and prospective Athena editions | Three core editions and ten prospective editions preserve branches/orders and reports. No-ALS editions resolve the software-event mismatch; originals retain barcode requirements. | Physical stimulus onset is not verified by software markers. |
| 9. Regional EEG distinction | Six separately identified ERP exploratory editions; original regional, motor, and SSVEP requirements remain enforced. | Missing electrode locations and actual optical timing require suitable hardware. |
| 10. Analysis defects | Context-aware motor/ERP selection, retained per-class motor checks, N2pc target-side selection, SVNA ranking/timestamp correction. | A software correction does not establish decoder generalization or the named ERP on Athena. |
| 11. Additional signals | Named independent sensor requirements throughout the compatibility registry; EEG-only rest adaptation has a revised scope. | RR, respiration, EDA, EOG and EMG must be independently available where required. |
| 12. Multiperson and analysis status | Participant/source counts and ownership for full hyperscanning; implemented, event-only and unavailable endpoint analysis states are explicit. | Independent physiological estimators and actual multiperson timing require their declared evidence. |

Original protocol definitions remain separately available. New adaptations have parent identities and source hashes. Original assignments, recordings, model files, and prior release archives are not rewritten.
