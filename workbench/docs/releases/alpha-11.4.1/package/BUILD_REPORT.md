## Reproduced defect and correction

The optical relative-hemoglobin reference had only a URL. Its missing identifier and citation caused the existing strict credit validator to reject the affected receipt's attribution block. A regression reproduced the failure after native optical calculation and a successfully validated execution receipt. The corrected structured references credit Delpy, Cope, van der Zee, Arridge, Wray and Wyatt (1988), while retaining the MNE fNIRS tutorial as separate methodological context.

The regression uses a synthetic verified profile and known relative-concentration inputs, invokes the shipped optical calculation through the real credit observer, creates a hash/inventory-validated COMPLETE receipt, aggregates credits and verifies the rendered HTML contains the original-method citation, MNE documentation reference and observed NumPy software credit. This checks the software path and synthetic algebra, not a real instrument or physiological estimate. Every active method reference also satisfies the receipt field contract. Strict rejection of malformed historical credit records remains tested; no old receipt is rewritten.

## Limits

No fresh-machine dependency installation, actual restart upgrade, provider request, real recording analysis, physical acquisition, model inference or scientific validation was performed for this patch.
