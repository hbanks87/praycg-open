# Time–Frequency Explorer in Alpha 10.5.1

The Explorer describes sensor activity across time/frequency. In Live Monitor use **Time–Frequency / Optical trends**. In Forge use **Analyze / explore** in Time–Frequency Explorer.

Measured EEG, conventional processing and compatible saved generated signals retain separate labels/provenance. Heatmaps and rotatable 3D sensor/surface views use channel names as the sensor axis. Quality support, units, reference and estimator belong with every comparison.

Alpha 10.5.1 adds XDF replay and raw optical trends/spectra. Playback speed affects presentation only, seeking rebuilds history and timing gaps remain explicit. Optical views use slower ranges and longer windows; hemoglobin conversion requires a separate verified profile.

See the [live/replay/optical guide](LIVE_REPLAY_OPTICAL_ALPHA_10_5_1.md) and [Forge guide](ANALYSIS_FORGE_ALPHA_10_5_1.md).
