The shipped current build receipt records 4,285 unique passing tests and six skips. Native acceptance records 93 checks separately. This publication review reran 93 focused checks and verified the exact archive, 1,789 distribution-manifest entries and shipped checksums. Separate original delivery receipts record successful runtime dependency audits on public and extracted layouts and 191 passing extracted tests; their summarized scope is in the repository review. These counts are not added to the unique full-regression total.

The restored Athena receipt retains its original 10.5.1 single-unit EEG acquisition/recording scope. Its exact bytes remain required; missing or changed evidence is rejected. Earlier installation, SDK, acquisition and reconstruction evidence remains historical. No fresh full installation, physical timing/acquisition, current SDK descriptor acceptance, optional Zuna inference or physiological validation is added.

The default incremental visual recipe still requires P7/P8 for gamma and Pz/P3/P4 for theta. Athena's four measured electrodes cannot supply these defaults. Completed CAI/NIP and experimental Autonomic state remain separate; raw EEG/RR cannot fabricate missing CAI, NIP or CAI-SID components. A deliberately later calibration start preserves the recording clock and does not relax support or gap checks. It does not guarantee successful calibration.

The source manifest retains an inherited `release_date` of `2026-09-30`. The actual GitHub publication date is October 9, 2026; current identity, source hashes and validation records are unchanged. Retained historical attribution headers and acceptance files keep their original scope.

Historical guide links in the complete changelog open the release containing the guide inside its ZIP.
