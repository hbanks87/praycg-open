# Public Alpha 11.2.2: workflow hardening

**Sealed and locally verified release candidate. GitHub publication and remote download verification remain pending.**

This release connects protocol preparation, recorded analysis, usable figures and evidence-grounded explanation more directly. It retains the independent PRAYCG AI Assistant. Private study software, stores, histories, recordings and provider credentials are not part of the public distribution.

The [cumulative change record since Alpha 10.5.4](../../proposed-alpha-11.2.1.md) remains the account of the intervening changes. The [11.2.1 documentation snapshot](../alpha-11.2.1/README.md) and all older records retain their original identities, checksums and verification scope. This patch adds the changes below; it does not retroactively change those packages or scientific results.

## Patch scope

- Repair release/catalog agreement so a version mismatch does not block valid Materials workflows or produce a cascade of historical-version messages.
- Offer views based on the selected recording and verified saved outputs. Keep raw traces and time-frequency displays separate from optional calibrated state estimates. Report loading and failures beside the action.
- Preserve source, channel, time-window, screening and uncertainty context in analysis explanations. Unavailable ECG or respiration must not erase available EEG or optical descriptions.
- Clarify completed process, available endpoint, missing prerequisite and failed execution. Narrower descriptive support is not a replacement for a strict full-montage method.
- Retain eye/activity context in the existing Recording conditions control, with optional plain-text detail, explicit post-hoc/unverified status and an immutable revision chain. Unknown conditions are not inferred from a recording name or its signals.
- Make a protocol's declared rating contract available to native analysis without assuming that all user-designed protocols share one scoring rule. Retain new scoring as post hoc for historical recordings where applicable.

- Repair the protocol-rating credit-record launch path and test managed launch as well as its numerical worker.
- Connect the optional installer to the seven-film collection and the original Lantern demonstration as separate, hash-pinned packages.
- Carry forward the complete research navigation, concept guides, algorithm map, bibliography and notices prepared in the [research update](../../../../docs/updates/2026-10-13-public-research-update.md).

The rating contract is optional in a newly reviewed protocol version. This release does not add one retrospectively to installed protocols. A historical protocol without a contract can receive per-node response descriptions when the events support them, but no new scale meaning, averaging rule or comparison is guessed.

## Public/private boundary

The public AI Assistant explains calculated evidence and drafts reviewable proposals. Analysis workers calculate measurements. Neither an explanatory model nor a successful software launch establishes a mental state, a physiological mechanism or clinical meaning. The assistant does not gain permission to arm equipment, change measurements or adapt a participant protocol.

Separate development technology is not required to install, record, analyze, author supported protocols or reopen a research bundle in the public Workbench.
