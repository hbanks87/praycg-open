# PRAYCG Workbench Public Alpha 11.2.2

This update hardens the path from protocol preparation to recorded analysis, useful figures and plain-English explanation. It also brings the public research navigation, source guides and optional stimulus downloads together. The public Workbench retains its independent PRAYCG AI Assistant; no private extension is required.

## What changed

- **Materials:** repairs release/catalog agreement and replaces the misleading historical-version dead end with the current protocol's actual preparation requirements.
- **Visual Analysis:** makes supported views and saved time-frequency results available for the selected recording without requiring an unrelated advanced state estimate. Source and failure details stay beside the action.
- **Analysis and explanations:** keeps execution status, recording integrity, usable descriptive measurements and unavailable endpoints distinct. Missing ECG or respiration no longer conceals available EEG or optical descriptions. Numerical statements retain their source and scope.
- **Recording context:** lets the operator record actual eye/activity context and a short note. Unknown remains unknown; revisions are explicitly post hoc, unverified context with preserved history, not inferred behavior.
- **Protocol ratings:** completes source-bound rating handoff, repairs the credits observer launch path and supports an optional versioned scoring contract for newly reviewed protocols. Existing protocols and historical scoring rules are not silently rewritten. Without a contract, supported per-node descriptions do not acquire guessed scale meanings or comparisons.
- **Optional movies:** adds one installer for the seven-film public collection and the original Lantern demonstration, supplied as two separately pinned packages. It offers local-ZIP fallback, storage/destination checks, safe repeat installation and verified selection in Materials. Eight masters are preparation inputs, not ready-to-run or scientifically approved protocol packages.
- **Research documentation:** restores clear routes to Opto-PING, research ladders and rungs, reproduction programs, five concept guides, the algorithm map and current bibliography. Original theory documents, historical records and upstream notices are preserved.

## Installation and preservation

Extract the complete Public archive to a new folder, run **INSTALL.bat**, then **START.bat**. Keep existing settings, study folders, recordings and configured Zuna environment/model paths. Do not overwrite an old study folder or reinstall Zuna simply to update the Workbench. Optional movies are a separate, deliberate installation.

The application ZIP does not include participant recordings, private study protocols, private assistant implementation or provider credentials. Review consent, identifiers, media rights and bundle contents before sharing any study.
