# Original-file locator

To find the destination of a file from the original repository layout, search the [preserved original-file index](https://github.com/hbanks87/praycg-open/blob/ecb6986651b3930d98fea9db1106069a7dbbd30b/docs/reorganization/original-file-index.md) for its former name or path. Each entry records the destination at the time of the reorganization. The [research index](../../research/README.md) and [documentation index](../README.md) lead to the maintained guides.
