# Public data boundary

Public examples in this repository should be one of:

- Synthetic data.
- Derived feature tables with no raw biometric time series from third parties.
- Self-run derived examples explicitly labeled as exploratory.
- No-copyright or Creative Commons demo media with license/attribution included.

Do not publish:

- Raw participant XDFs unless consent and deidentification are explicit.
- Copyrighted film clips.
- Private self-report text from other people.
- Identifying metadata.
