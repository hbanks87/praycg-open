# Supplemental Conceptual Context

This folder contains optional conceptual and philosophical materials related to PR-AYC-G.

These files are not required to evaluate the empirical protocol. They do not add evidence to the EEG, autonomic, respiration, artifact, or self-report analyses. Their purpose is to preserve the broader interpretive register of the project: PR-AYC-G as a bounded scientific protocol and also as a conceptual artwork about measurement culture, meaning, and the human impulse to make care legible.

The technical documents should be evaluated on their own terms:

* stimulus design,
* phase-scrambled controls,
* contextual override,
* event timing,
* EEG/HRV/respiration streams,
* artifact rejection,
* retained-window reporting,
* task compliance,
* self-report,
* demand-characteristic covariates,
* statistical contrasts,
* falsification logic.

The conceptual documents ask a different question: why did it require a copper-lined chamber, sensors, timestamps, and a statistical pipeline to ask whether a story changed the body?

## Reading rule

Read this folder only after the empirical theory, protocol, and methods are clear.

The conceptual register should not be used to make claims about neural mechanisms, consciousness, clinical efficacy, quantum physics, or participant authenticity. It is a context layer, not an evidence layer.
