# Contact pilot: gold-plated but not gold-record

The Contact pilot is included as a public-safe derived-output example because it is currently the clearest demonstration of the analysis folder structure and a strong exploratory Target-favoring result.

It is **not** a gold record. Do not treat it as confirmatory evidence.

Reason for caution:

- It was conceptually predeclared but not runner-registered with a locked anchor JSON.
- It is a single-participant self-run.
- It does not include the copyrighted stimulus video.
- It is useful for demonstrating the analysis suite and file layout, not for making a final scientific claim.
