# Release and repository history

## Current release — Alpha 10.5.2

The [Alpha 10.5.2 release](https://github.com/hbanks87/praycg-open/releases/tag/PRAYCG_Workbench_A10.5.2) provides the complete Workbench ZIP, SHA-256 checksum, changelog, installation guide and validation receipts. Published October 8, 2026, it adds Gamma Scalpel 2.0 and adaptive optical exploration, including the Live Time–Frequency and recording/Forge improvements from 10.5.0 and 10.5.1.

Read the [cumulative changelog](../../workbench/CHANGELOG.md), [current guide collection](../../workbench/docs/releases/alpha-10.5.2/README.md), and [release review](../../workbench/docs/releases/alpha-10.5.2/REPOSITORY_RELEASE_REVIEW.json). ## Reorganization versus release changes

This repository redesign changes public navigation and file placement. It does not rebuild the application, alter protocol markers, rewrite recorded studies or certify historical software against current environments.

The preserved root pages in [project history](../project-history/original-root/) document the previous repository presentation. They may contain historical links; use current navigation or the original-file locator when those links no longer resolve.
