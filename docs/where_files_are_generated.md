# Where files are generated: familiarity CSV, scene map CSV, annotation CSV, and feature table CSV

## Short rule

```text
MediaPrep creates stimulus files and cue/anchor scaffolds.
The protocol runner records what was actually used.
The Master Comprehensive Suite creates physiology feature tables and MRED outputs.
Familiarity, scene-map, and annotation CSVs are analysis-side covariates or bridge files.
```

## Quick table

| File | Generated by | Usual location | Purpose |
|---|---|---|---|
| MRED familiarity CSV | Template + manual entry | `analysis_inputs/<run>/` | Novelty/familiarity/personal resonance covariates |
| MRED scene map CSV | Template from anchor schedule | `analysis_inputs/<run>/` | Anchor ID -> scene/time/prediction map |
| Annotation CSV | Anchor + scene map + optional analysis results | `analysis_inputs/<run>/` or `analysis_outputs/<run>/tables/` | Human-readable bridge for reports/visual overlays |
| Feature table CSV | Master Comprehensive Suite | `analysis_outputs/<run>/tables/*time_resolved_feature_frame*.csv` | Time-resolved physiology/features |

## 1. MRED familiarity CSV

This is usually manual. Copy a template:

```bat
copy templates\mred_familiarity_covariates_template.csv C:\PRAYCGnalysis_inputs\MyRun\MyRun_MRED_familiarity_covariates.csv
```

Fill one row per anchor. Use values 0-9 for prior exposure, rememberedness, anticipation, new meaning today, personal resonance, and related fields.

## 2. MRED scene map CSV

Create from the anchor JSON/CSV:

```text
anchor_id,condition_scope,rendered_time_sec,scene_label,scene_description,claim_level
```

For blind/novelty-preserving runs, keep labels neutral before acquisition. After the run, create a revealed version if needed.

## 3. Annotation CSV

Bridge file for human review:

```text
anchor_id,condition,start_sec,end_sec,time_sec,label,claim_level,category,notes
```

Create from the anchor schedule by subtracting/adding pre/post windows around `rendered_time_sec`.

## 4. Feature table CSV

This is generated by the Master Comprehensive Suite after XDF analysis:

```text
<Master Comprehensive output>/tables/<run>_time_resolved_feature_frame.csv
```

Visualizer sidecars such as `*_features_used.csv` are subsets used for rendering, not the canonical feature table.

## Search commands

```bat
dir /s /b *familiarity*.csv
dir /s /b *scene_map*.csv
dir /s /b *annotation*.csv
dir /s /b *time_resolved_feature_frame*.csv
```
