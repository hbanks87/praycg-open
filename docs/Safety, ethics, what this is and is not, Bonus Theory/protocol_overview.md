# Protocol overview

PRAYCG2.0 uses a consolidated self-report layer and a three-arm stimulus structure.

## Main arms

| Arm | What is shown | What the participant does | What it tests |
|---|---|---|---|
| Control | Phase-scrambled version of cue-embedded target | Watch normally | Low-level sensory entrainment |
| Target | Intact cue-embedded narrative | Watch naturally | Accessible meaning |
| Contextual Override | Same intact cue-embedded narrative | Perform running-sum cue task | Analytic extraction / task stance |

## Primary endpoint direction

The recommended confirmatory compression is A-MRED / MRED-Peak-Resolution:

```text
Timing/QC + StimulusFingerprint/CET-R + artifact/confound gates -> A-MRED / MRED-Peak-Resolution
```

All other modules remain useful, but not all are equal evidence.
