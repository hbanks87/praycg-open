This is a selected source snapshot, not a copy of the full application tree. Some links inside the unchanged package citation document point to historical attribution inventories, notices and Zuna records that exist only in the complete application archive. Those links were verified against that archive; they are **not** available as clickable targets inside this small repository snapshot. Use the [repository master attribution](../../../CITATIONS_AND_ATTRIBUTION.md), [bibliography](../../../research/bibliography/README.md) and preserved notice links above for repository navigation, or open the full extracted archive for the package-internal references. The original citation file has not been rewritten to hide that distinction.

The protocol-ratings observer metadata correction proposed in the [historical 11.2.1 review](../alpha-11.2.1/proposed-fixes/README.md) is applied in 11.2.2. Fresh managed-wrapper tests exercise the corrected worker launch alongside rating calculations and malformed-input handling. The [sealed build report](../../../workbench/docs/releases/alpha-11.2.2/package/BUILD_REPORT.md) records 545 unique selected targeted checks for the full release cycle; that is not 545 attribution tests. The older proposal, failed-launch observation and original registry remain unchanged as historical evidence.

Declared references, observed software imports, entered functions and successfully estimated endpoints remain different things. Credits must preserve actual execution state. A planned, skipped, failed or unavailable analysis does not become a completed result because its citation is present.

The [current bibliography](../../../research/bibliography/README.md) remains a readable method-to-source guide. Exact upstream license and copyright notices are retained separately. Neither PRAYCG's root license nor a bibliography replaces those terms or transfers upstream authorship. EEGLAB remains an external reference, not a newly bundled backend. This supplement does not claim complete historical source-origin clearance, every transitive binary notice, or full method-level execution coverage.

The optional seven-film and original Lantern packages preserve their own source-edition hashes and media rights records. A stimulus checksum verifies identity; it does not establish participant consent, suitability for a particular experiment or scientific validity.
