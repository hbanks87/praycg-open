# GitHub upload map

Recommended GitHub contents:

```text
README.md
LICENSE
CITATION.cff
CONTRIBUTING.md
CODE_OF_CONDUCT.md
DISCLAIMER.md
CHANGELOG.md
.gitignore
docs/
hardware/
software/
examples/
templates/
```

Avoid uploading raw XDF, copyrighted media, private participant data, or large videos unless they are explicitly public-safe and under size limits.

For large media or full datasets, prefer OSF and link from GitHub.
