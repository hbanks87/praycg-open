# PRAYCG Control Center — Master Changelog

## Scope and how to read this history

This record follows the retained software lineage from the v0.95a baseline through v1.0.0-alpha.10.0.4, oldest first. “Alpha” below abbreviates the v1.0.0-alpha version prefix. Entries describe changes documented in the corresponding retained package, not proposed features or promises that every earlier defect was eliminated.

The evidence comprises 42 numbered package identities, including v0.95a, and two separately named Alpha 9.9.0 catalog-repair archives. Same-version release notes, READMEs and version manifests take precedence over later summaries. Some early packages use their README as their release record. The Alpha 10.0.1–10.0.4 public changelogs supply their detailed current deltas. This document is a historical synthesis, not a replacement for the current installation guide or release-specific validation evidence.

Version gaps are not filled by inference. Alpha 9.1/9.2 and 9.7/9.8 appear as development scopes incorporated into later cumulative releases; separate packages were not found. No corresponding retained numbered artifact was found for Alpha 8.1, 8.5.0, 9.4, 9.5, 9.9.1 or 9.9.2. The two catalog-repair filenames do not establish releases 9.9.1 or 9.9.2. Internal component versions also differ legitimately from the Control Center package version.

## v0.95a — Retained baseline and installation repair

v0.95a retained the existing native acquisition and analysis foundation while repairing installation compatibility. It bounded setuptools to accommodate BrainFlow's fallback dependency, explicitly required pyserial, and added hardware-free checks of native-library loading and package metadata. Installer success depended on those checks. Public version labels were updated while the v0.95 settings schema remained; token-bearing OSF links were removed from public documentation. Acquisition algorithms, native protocol sequences, analysis formulas, eligibility rules and frozen exploratory candidates were not changed by this hotfix.

## Alpha 1 — Integrated platform foundation

The first integrated platform release added Protocol Forge, a reviewed declarative-module runner, Hardware Registry with canonical roles, an observer-first Acquisition Supervisor, and combined study/session locks. Analysis capability resolution, marker/timing contracts, BIDS export, privacy scanning and analysis-only environment specifications extended the platform. Cue-Locked Gamma Forensics remained exploratory. The Platform Alpha/Workbench interface sat alongside preserved PRAYCG3, PRAYCG4 and SMG structures. Reported software tests did not establish physical-device operation, interactive presentation timing, human feasibility, external BIDS conformance or container execution.

## Alpha 2 — One console and one-use acquisition authority

Parallel workbench surfaces were consolidated into an operator console. Runtime locks bound the exact protocol, runner, engine and media to a fresh run identifier and unused output directory. A shared-log-root owner and process-bound, one-use lease governed acquisition, with heartbeats, interrupted-run finalization and ordered downstream evidence. Unrelated child processes could not inherit acquisition authority. EEG-plus-ALS accounting was corrected to four actual outlets, and stream health was separated from the controlled optical-placement check. A selected protocol or approved profile still did not itself authorize acquisition.

## Alpha 3 — Runnable Protocol Atlas

Eleven Atlas adaptations joined three native protocols, yielding 14 entries. Initial families covered rest, narrative audio, repeated viewing, event segmentation, visual oddball, motor imagery, repeated clips and sequential visual narrative. Individual wrappers used a shared declarative engine with asset contracts, response records and analysis handoffs. Deterministic, asset-aware compilation, recursive validation and exact external-asset hashes strengthened locks. Discovery remained confined to packaged roots; reviewed defaults governed parameters and interrupted Atlas acquisition could not resume. Software flip markers were not physical photon-onset measurements.

## Alpha 4 — Stimulus, hardware and analysis catalogs

Stimulus Forge and Library introduced typed packs, including four CC0 demonstration packs covering the 14 protocols. The hardware foundation cataloged eight adapters and fifteen routes, with a generic serial/UDP EDA/PPG prototype. Ten analysis modules received discovery/readiness metadata. Supplied third-party bridge archives contributed metadata rather than copied source. Demonstration material remained `DEMO_ONLY`; catalog inclusion, synthetic transport results and discoverability did not approve physical hardware, participant collection or scientific endpoints.

## Alpha 5 — Connected preparation workflow

Seven work areas connected protocol selection, compatible stimuli, reviewed hardware, running and analysis. Locking a protocol filtered preparation choices; incompatible changes cleared or invalidated dependent selections. Governed master-video intake included an explicit checked, backed-up migration of older master-media tags. Hardware used a validated tray, reviewed profile and separate interface lock, with bridge actions revalidated when clicked. Protocol AI Docs Builder produced hashed, non-executable design packets. A design document could not install a runner or acquire runtime authority.

## Alpha 6 — Persistent studies and governed analysis

Study Workspace persisted the progression from protocol and materials through hardware, acquisition, QC, analysis, review and export. Upstream changes preserved evidence while invalidating dependent approvals. Eleven execution modules gained registry-bound orchestration, eligibility checks, dependency planning, immutable pre-outcome locks and separately labeled post-lock exploratory additions. Local results bundles combined allowlisted derived outputs, redacted provenance, review records and checksums. Raw biosignals were excluded from that export path; local bundle creation neither uploaded the study nor granted publication approval.

## Alpha 6.1 — Mature Endpoint Atlas integration

Seventeen additional PRAYCG runners expanded the catalog to 31 entries: 28 Atlas and three native. ## Alpha 8 — Public-study adaptations and live equipment visibility

Twelve adaptations expanded Atlas to 40 protocols plus three native entries. Added families included ERP CORE tasks, inner speech, meditation and SSVEP. ## Alpha 8.2 — Numeric transport and bounded bench testing

EEG, auxiliary and ALS chunks were explicitly flushed with sample timestamps, addressing outlets that could be discovered but delivered no numeric data. The live inlet was opened once rather than twice, bringing opening failures inside the error boundary. The recorded same-host measurements supported a software resource-use repair, not a general guarantee of memory consumption, hardware performance or uninterrupted long-duration acquisition.

## Boundaries that persist across the lineage

Software completion, byte integrity, catalog membership, a readable report and scientific validity remain different claims. Retained tests describe their particular software, synthetic or same-machine scope; they do not by themselves establish safe human-connected hardware, display/photodiode timing, clinical meaning, physiological origin, construct validity, causal interpretation, power or population generalization.

Original recordings, immutable locks and prior results remain provenance, including failed, incomplete, contaminated, noncanonical and non-estimable outcomes. Repairs must not retrospectively improve their classification. New analyses, summaries and revisions require their own evidence and honest prospective/post-hoc labels. Public titles and source citations do not grant endorsement, replication equivalence or rights to redistribute external materials. Local exports still require privacy, consent and licensing review before sharing. Consult the current guide and the exact release's validation artifacts for operational instructions and executed coverage.
