Anchor-Locked Meaning Recognition / Encoding Dissociation. A predeclared anchor is strongest when Target shows both recognition and delayed integration greater than Control and Override after QC.

Acute recognition + integration event. Contact-style meaning shock or model expansion.

Delayed reflective/regulatory recovery. Field-of-Dreams-style closure or afterglow profile.
