# Changelog

## v0.4.0

Initial PRAYCG Control Center release.

- Main dashboard for PRAYCG workflow.
- Stimulus Library with MP4 copy, SHA-256 hashing, and basic validation.
- Acquisition Panel with launch buttons for Polar H10, Vernier Respiration Belt, BrainFlow EEG-only, BrainFlow EEG+ALS, LSL stream checking, Signal Quality Index, ALS screen pulse barcode, and LabRecorder.
- PsychoPy-safe runner launcher for users whose PRAYCG2.0 runner works reliably only from PsychoPy Coder.
- Analysis tab for launching Master Suite, Visualizer, and Offline Interpreter.
- Settings tab for tool paths.
- Attached Polar H10 and Vernier streamers included.
