# PRAYCG1.6S Browse-Media Windowed Runner

PRAYCG1.6S is an acquisition-script patch for the PRAYCG1.6R windowed protocol runner.

It preserves the v1.6R transition correction:

```text
self-report input
→ press SPACE to proceed
→ 8-10 second stillness countdown
→ next clip starts automatically
```

and adds a new initial browse-file GUI for selecting the exact stimulus files before the run.

## New in v1.6S

The first window now lets the operator choose:

```text
Control video
Target video
Contextual Override video
Event cue schedule JSON
```

with normal Browse buttons. This removes the fragile fixed-filename assumption and prevents runs from silently using stale or missing media paths.

## Required files

Use media generated by the PRAYCG MediaPrep pipeline whenever possible:

```text
stimulus_control_cued_phase_scrambled_<project>_v1_6Q.mp4
stimulus_target_cued_<project>_v1_6Q.mp4
stimulus_override_cued_<project>_v1_6Q.mp4
cue_schedule_<project>_v1_6Q.json
```

Target and Contextual Override should normally be bit-identical cue-embedded media files; only the participant instruction should differ.

## Validation

Before the run starts, v1.6S validates that:

```text
all three video files exist
the cue schedule JSON exists
the cue schedule JSON contains cue_events
expected_sum is available in the JSON or entered manually
```

The GUI also checks whether Target and Override have matching SHA-256 hashes and reports the result.

If the cue schedule fails to load, the script aborts before the experiment begins. This is intentional.

## Run command

From the unzipped tool folder:

```bash
python scripts\run_PRAYCG1_6S_BrowseMedia_Windowed.py
```

or:

```bash
python scripts\run_praycg_v1_6S.py
```

or double-click:

```text
examples\run_PRAYCG1_6S_windows.bat
```

## LSL / LabRecorder flow

1. Start the OpenBCI BrainFlow-to-LSL bridge or other EEG LSL stream.
2. Start Polar and Vernier streams if used.
3. Launch PRAYCG1.6S.
4. Select files in the browse GUI.
5. The script creates `StasisMarkers`.
6. The script opens a windowed LabRecorder preflight hold.
7. In LabRecorder, click Update and confirm streams are checked.
8. Start LabRecorder.
9. Return to PRAYCG and right-click to begin.

Do not start LabRecorder before the marker stream is online.

## Output logs

The local run log now includes a media-selection config JSON:

```text
*_run_config_media_selection.json
```

It records selected paths, SHA-256 hashes, cue schedule summary, and whether Target/Override hashes match.

## Analysis implications

The selected cue schedule is the event cue JSON used to emit cue markers during Target and Contextual Override. This makes post-processing cleaner because the analysis suite can recover cue count, expected sum, and media provenance from the run logs.
