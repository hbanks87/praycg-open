# Topo-OSM / PR-AYC-G Claim Boundary

**Status:** research architecture and protocol documentation. Not clinical guidance. Not proof of consciousness. Not proof of molecular memory.

## Core boundary

In the present human EEG implementation, Opto-Structural Memory (OSM) is treated as a **macroscopic network-state hypothesis**: structured audiovisual narrative input may induce state-dependent changes in the topology and persistence of brain-body dynamics.

No inference is made from scalp EEG to microtubular, biophotonic, cytoskeletal, or molecular memory mechanisms.

## What PR-AYC-G can test now

PR-AYC-G can test whether a narrative stimulus produces measurable, condition-specific changes in:

- scalp EEG work-signal features such as MeaningGamma, TaskGamma, TSP, theta, and alpha;
- event-level state-transition dynamics around predeclared media-structural anchors;
- MRED meaning recognition versus encoding/integration dissociations;
- NAST narrative absorption state transitions;
- OCM/RSM analytic override microstates;
- autonomic and respiratory covariates;
- confound-sensitive interpretation layers.

## What PR-AYC-G cannot test now

PR-AYC-G cannot directly detect or confirm:

- microtubule resonance;
- biophotonic flickering;
- tubulin state changes;
- cytoskeletal molecular memory;
- DNA memory storage;
- cellular engram architecture;
- a biological hidden variable Y_cell;
- consciousness, soul, or metaphysical truth.

## Terminology rule

Use **K_HT_topo** or **K_HT-topo** for human-scale event-level coupling between observable work signals and inferred network-state topology.

Reserve **K_OSM** for future mechanism-specific evidence that directly measures the relevant biological substrate.

## Language to remove from peer-review-facing docs

Do not use the following as empirical claims:

- EEG proves microtubule resonance.
- Gamma proves meaning.
- ALS detects biological Y.
- Biophotons are visible through scalp EEG.
- K_HT is K_OSM.
- Narrative meaning physically proves molecular memory.

## Safe one-sentence claim

PR-AYC-G tests whether narrative meaning produces measurable, confound-controlled changes in brain-body state topology.
