# PRAYCG1.9 KISS Run Order

1. Start acquisition streams.
2. Start the PRAYCG1.9 runner.
3. Confirm StasisMarkers online before LabRecorder starts.
4. Select Control, Target, Override, cue schedule, and optional anchor file.
5. Validate Target/Override hash match.
6. Use pre-run cue/audio calibration.
7. Run Baseline, Control, Washout 1, Target, Washout 2, Override, Washout 3.
8. Complete per-branch confound reports.
9. Run final reflection baseline and final master subjective report.
10. Feed event log, cue schedule, XDF, OCM025 table, and confound reports into Master Suite v1.4.6+.
