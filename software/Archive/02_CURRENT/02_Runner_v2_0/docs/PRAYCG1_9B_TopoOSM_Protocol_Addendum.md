# PRAYCG1.9B Topo-OSM Protocol Addendum

PRAYCG1.9B keeps the PRAYCG1.9 confound-aware runner and adds a peer-review-facing interpretation layer.

## Operationally unchanged

The default runner remains a clean three-arm PR-AYC-G protocol:

1. Phase-scrambled Control.
2. Natural Target.
3. Contextual Override with analytic/running-sum task.

The runner still collects pre-run display/audio calibration, per-branch confound reports, final reflection baseline, final master subjective report, and override-specific running-sum reports.

## Interpretive update

All human EEG claims should be interpreted as **network-state topology** claims, not cellular OSM claims.

## New post-run wording

Use: "Did this scene feel meaningful, familiar, newly integrating, or recognized but already known?"

Avoid: "Did this prove memory encoding?"

## Saturday clean-run rule

For Contact and Eternal Sunshine, run clean anchor-locked PRAYCG1.9B without Subtitle Override unless the run is explicitly exploratory. Subtitle Override is a separate protocol variant.
