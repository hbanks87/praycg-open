# NIP/BIT/CII/IAQ and CET/EET method note

NIP translates an attention-plus-resonance immersion idea into PRAYCG observables: semantic attention/meaning recognition (`MeaningGamma`, `TSP`, `NAST`) multiplied by delayed integration/resonance (`theta_future_10_30`, `theta_integration`, `K_HT-topo` where available).

BIT is not a mean. It is a gate. High attention without integration is not a full BIT pass.

CII is the mean NIP density across an anchor window. It is duration-normalized, so longer scenes are not automatically larger.

IAQ compares Target to Contextual Override. Positive IAQ means Override attenuated the NIP proxy relative to natural viewing.

CET models exogenous entrainment from cue trains and, where media features are supplied, visual/audio rhythms. CET-R residualizes NIP/CII against available exogenous regressors. EET estimates after-state/echo similarity into washout or Baseline 2.
