# PRAYCG1.8 KISS Run Order

1. Start hardware streams.
2. Confirm LabRecorder can see all required LSL streams.
3. Launch PRAYCG1.8.
4. Select Control, Target, Override, and cue schedule JSON.
5. Use `movie_display_mode=safe_fit` and `movie_safe_fit_fraction=0.92` as the default on the new laptop.
6. Complete the LabRecorder preflight hold.
7. Run the standard protocol.
8. After Washout 3 ratings, follow the final reflection baseline instructions.
9. Complete the final master subjective report.
10. Save frozen notes before any physiology analysis.

The final reflection baseline is not a neutral baseline. It is the physiological footprint of deliberate cross-condition reflection after all branches.
