# Acquisition Options

## TSC-grade timing route
Use `BrainFlow_ALS_PT19_Bridge_v1_4_TSC_grade` when you want EEG plus ALS-PT19 physical display-timing validation.

## Home-user route
Use `BrainFlow_EEGOnly_Home_Bridge_v1_0` when the user will not wire an ALS sensor. This is easier, but it does not physically validate display onset.

Do not run OpenBCI GUI and BrainFlow on the same serial port at the same time.
