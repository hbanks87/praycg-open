# Claims Boundary

PR-AYC-G is an exploratory psychophysiology protocol asking whether narrative meaning has measurable timing, shape, and physiological consequence beyond matched audiovisual stimulation and analytic task stance.

OSM / Opto-PING is a conditional theory and synthetic reproducibility ladder. Rung 0 scripts test whether a reciprocal hidden-state model can be identified in simulated data and controlled against null alternatives.

## Non-claims

This operations pack does not prove:

- consciousness;
- souls or metaphysics;
- love as a literal physical force;
- OSM biology;
- microtubular memory;
- biophotonic memory;
- clinical efficacy;
- human EEG access to cellular hidden-Y.

## Operational rule

K alone is not enough. Theta handoff alone is not enough. CandidateLocal_KHT requires local coupling, theta carryover, condition specificity, artifact/timing pass, and appropriate claim-level labeling.
