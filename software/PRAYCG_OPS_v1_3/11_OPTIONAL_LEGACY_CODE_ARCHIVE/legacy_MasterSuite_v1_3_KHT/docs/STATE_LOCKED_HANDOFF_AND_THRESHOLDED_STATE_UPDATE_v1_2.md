# State-Locked Handoff and Thresholded State-Update Modules v1.2

State-Locked Handoff Alignment preserves stimulus-locked analysis while adding a state-time coordinate system. A candidate gamma/TSP taper or frozen annotation endpoint defines `t0`; theta and autonomic outcomes are tested after that anchor.

ThresholdedStateUpdate_v1 summarizes candidate sequences:

```text
meaning-candidate intake -> peak/taper -> theta integration -> autonomic settling
```

Both modules are exploratory unless the annotation CSV, anchor feature, taper rule, lag windows, and artifact/respiration controls are frozen before analysis.
