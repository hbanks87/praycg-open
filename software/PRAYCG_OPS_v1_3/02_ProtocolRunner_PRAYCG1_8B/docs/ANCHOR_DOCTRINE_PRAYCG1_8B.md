# PRAYCG1.8B Anchor Doctrine

## Retired as confirmatory

Retrospective second-level subject time estimates, such as "I think meaning happened around 60-90 seconds," are no longer primary confirmatory anchors.

## Preserved and upgraded

Frozen timing remains essential, but it should come from media or an algorithmic rule:

- `media_structural`: exact scene, line, cut, reveal, gesture, or visual event in the rendered video.
- `algorithmic_predeclared`: locked physiological rule specified before analysis.
- `subjective_scene_postrun`: qualitative scene report mapped later to time by a separate annotation process; not confirmatory unless the mapping rule was preregistered.
- `physiology_exploratory`: discovered after viewing the data; useful only as a future-freeze candidate.

## Human-event lock logic

A future CandidateLocal_KHT module should require:

1. predeclared anchor or frozen algorithm,
2. local K_HT-like coupling against random-anchor/null windows,
3. theta carryover after the gamma/TSP peak or taper,
4. Target stronger than matched Control and Contextual Override,
5. artifact veto pass,
6. timing/metrology pass,
7. self-report consistency at the scene level.

K alone is not enough. Handoff alone is not enough. Subjective report alone is not enough.
