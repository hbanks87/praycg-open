Opto-PING asks whether a hidden candidate state could be reciprocally coupled to a gamma-like electrical oscillator. The Rung 0 ladder is synthetic. It verifies analysis behavior in simulated data.

## Everyday explanation

```text

  orthodox excitatory-inhibitory circuit model for gamma.

  adds a hidden candidate state Y(t) and asks whether E(t) and Y(t) form a reciprocal loop.

K:
  composite loop endpoint, usually K = sqrt(eta_E * zeta_E).
```
