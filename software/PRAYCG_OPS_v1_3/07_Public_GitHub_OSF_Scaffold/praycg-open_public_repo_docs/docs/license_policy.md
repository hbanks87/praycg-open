# License policy

Suggested repository policy:

```text
Code: Apache License 2.0
Scientific protocols, hardware guides, and analysis documentation: CC BY 4.0 unless otherwise marked
Philosophical / cultural essays: choose CC BY 4.0 or another Creative Commons license intentionally
Synthetic demo data: CC0 or CC BY 4.0
```

## Why not one license for everything?

Software, hardware documentation, scientific protocols, public essays, and demo data have different reuse patterns. A simple root `LICENSE` can cover code, but docs and hardware guides should carry their own license notice when necessary.

## Media exception

No copyrighted stimulus media are included or licensed by this repository. Users must provide lawful media separately.

## Participant data exception

Human data should not be public unless consent, de-identification, and sharing rules explicitly allow it.
