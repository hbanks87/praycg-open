# Quick boundary sheet

## Safe one-liner

PR-AYC-G is an exploratory psychophysiology protocol for testing whether narrative meaning has measurable timing, shape, and physiological consequence beyond matched audiovisual stimulation and analytic task stance.

## What not to say

- EEG proves consciousness.
- Gamma proves meaning.
- TSP proves STS/MTG activity.
- K_HT proves K_OSM.
- Human PR-AYC-G proves microtubules, biophotons, or OSM.
- The Box proves the effect.
- TSC acceptance validates the mechanism.

## What to say instead

- Gamma/TSP are artifact-sensitive candidate work signals.
- TSP is a posterior-temporal scalp proxy, not source localization.
- K_HT is a human-translation proxy.
- OSM remains a conditional mechanism hypothesis.
- Rung 0 is synthetic identifiability/specificity work.
- ALS validates display timing and belongs to input vector u(t), not hidden biological Y(t).
