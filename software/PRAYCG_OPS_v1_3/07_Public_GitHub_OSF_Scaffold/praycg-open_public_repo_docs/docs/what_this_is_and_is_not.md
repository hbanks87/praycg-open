# What this is and what this is not

## What this is

PR-AYC-G is an exploratory open psychophysiology protocol and analysis suite for testing whether narrative meaning has measurable timing, shape, and physiological consequence beyond matched audiovisual stimulation and analytic task stance.

The project includes:

- stimulus preparation tools;
- an OpenBCI / BrainFlow / ALS-PT19 acquisition pathway;
- a protocol runner;
- a Master Comprehensive Analysis Suite;
- synchronized visual review tools;
- Box / environmental-control hardware documentation;
- synthetic Opto-PING reproducibility gates;
- public theory and TSC-facing handouts.

## What this is not

This is not:

- a proof of consciousness;
- a proof of souls;
- a proof that love is a physical force;
- a clinical or therapeutic device;
- a diagnostic system;
- a validated medical protocol;
- proof of Opto-Structural Memory;
- proof of microtubular memory;
- proof of biophotonic memory;
- proof that scalp EEG detects a cellular hidden variable;
- permission to bypass IRB or human-subjects review.

## The clean empirical question

The clean PR-AYC-G question is:

```text
When a person receives an intact meaningful narrative, does the measured body-brain state differ from:

1. the same source material with recognizable meaning destroyed, and
2. the same intact stimulus viewed under analytic task demand?
```

## Claim ladder

```text
Allowed now:
  exploratory feasibility, method development, synthetic identifiability, null-aware specificity testing.

Allowed after stronger replication:
  candidate psychophysiological effects under specified controls.

Not allowed without direct mechanism-specific evidence:
  cellular OSM, microtubular memory, biophotonic memory, hidden-Y biology, consciousness proof.
```

## Register separation

This project has several registers:

```text
Protocol / software / hardware:
  operational and empirical.

Opto-PING / OSM:
  conditional mechanism hypothesis and synthetic-model testing.

Manifesto / cultural theory:
  philosophical and artistic companion material.
```

Do not use philosophical companion essays as empirical evidence.
