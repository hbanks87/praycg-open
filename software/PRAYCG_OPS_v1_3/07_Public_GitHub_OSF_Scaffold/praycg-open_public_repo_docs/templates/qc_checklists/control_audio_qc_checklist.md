# Control audio QC checklist

## Required manual check

Listen to the full phase-scrambled control using the same headphones/speaker settings used for the protocol.

## Pass criteria

- No recognizable spoken words.
- No intelligible sentence fragments.
- No distinct musical melody carrying narrative recognition.
- Loudness/envelope broadly tracks the original.
- The control sounds like speech-shaped or scene-shaped noise, not understandable dialogue.

## Record

```text
Audio intelligibility rating 0-9:
Any recognizable words? yes / no
Any recognizable music/melody? yes / no
QC verdict: PASS / FAIL / PILOT ONLY
```

## Boundary

The automated tool cannot certify unintelligibility. Human QC remains mandatory.
