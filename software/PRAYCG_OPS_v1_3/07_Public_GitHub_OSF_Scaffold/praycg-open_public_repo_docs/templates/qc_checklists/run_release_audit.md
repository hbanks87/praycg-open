# Public release audit

Before making a run public, confirm:

```text
No copyrighted stimulus video/audio included.
No private participant identifiers unless consented.
No private emails.
No home/location metadata.
No API keys or secrets.
No raw data without sharing permission.
No overclaiming language.
Run status clearly labeled: confirmatory / exploratory / pilot-only / invalid.
Timing status labeled.
Artifact caveats labeled.
Self-report status labeled.
```
