# Grounding and electrical safety

## High-level warning

Grounding mistakes can create shock hazards, ground loops, and equipment damage. This repository does not certify a safe grounding design.

## Rules

- Do not modify mains wiring.
- Do not connect experimental copper mesh to unknown electrical ground.
- Do not use the participant as part of any ground path.
- Do not assume an earth rod is safe just because it is physically in the ground.
- Consult a qualified electrician or relevant professional when grounding choices are unclear.
- Keep equipment on appropriate battery/isolated power when feasible.
- Maintain emergency exit and external access.

## Shielding vs safety

A better electromagnetic shield is not worth an unsafe electrical condition. Safety wins.

## Recommended documentation

Before a serious run, document:

```text
mesh bonding points
grounding rod location if used
ground cable route
power source locations
participant seat position
exit path
ventilation path
trip hazards removed
```

## One-point reference principle

If using a shield ground, prefer a clearly documented single reference point rather than many accidental connections. Avoid multiple unknown ground paths.

## Equipment placement

Keep AC adapters, extension cords, chargers, lighting, fans, and laptop power bricks outside or away from sensitive leads when possible. Battery power is often cleaner and safer for pilot tests, but battery devices still require safe cable routing and heat monitoring.
