# The Box - open hardware documentation

The Box is a Faraday-style environmental-control and art/science apparatus for low-cost psychophysiology recording. It is intended to reduce environmental noise, standardize context, and make the measurement chain more accountable.

## What it is

```text
A large mesh-lined environmental-control chamber for experimental EEG/physiology sessions.
```

## What it is not

```text
Not a medical device.
Not a therapeutic device.
Not a certified shielded room.
Not proof of PR-AYC-G.
Not proof of OSM.
Not safe to build without practical safety review.
```

## Safety first

Do not modify mains wiring. Do not connect to unknown electrical grounds. Maintain ventilation, fire safety, emergency exit, cable management, and external access. If in doubt, consult a qualified electrician or relevant professional.

## Public photos

Before uploading photos:

- strip EXIF/GPS metadata;
- remove private location identifiers;
- avoid showing faces unless consented;
- avoid showing addresses, license plates, personal documents, or private surroundings.
