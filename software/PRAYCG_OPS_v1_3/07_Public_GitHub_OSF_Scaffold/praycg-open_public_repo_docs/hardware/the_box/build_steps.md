# The Box build steps

This is a public-safe build outline. Adapt to local safety requirements, materials, and space constraints.

## Phase 0 - Safety review

Before construction:

- identify emergency exit path;
- confirm ventilation;
- remove trip hazards;
- plan cable routing;
- decide where electronics sit;
- do not modify mains wiring;
- get grounding/electrical advice if unsure.

## Phase 1 - Ground and foundation

1. Choose a location away from large metal walls, water, heat sources, and heavy foot traffic.
2. Lay a dielectric/insulating floor barrier if building over concrete or near rebar.
3. If using an earth ground, install only with proper safety review.
4. Keep the build mechanically stable before adding mesh.

## Phase 2 - PVC skeletal frame

1. Assemble the bottom frame.
2. Dry-fit vertical supports.
3. Assemble top frame and roof/cross-brace.
4. Confirm square, level, and stable geometry.
5. Cement only after fit is correct and emergency access is planned.

## Phase 3 - Mesh envelope

1. Unroll wide copper mesh vertically.
2. Attach mesh to frame with zip ties or other nonconductive fasteners.
3. Overlap adjacent mesh panels by approximately 2 inches.
4. Fold and flatten overlap where possible.
5. Tape the seam with conductive copper foil tape.
6. Bond wall mesh to floor mesh.

## Phase 4 - Door / flap

1. Use an oversized mesh flap, not a hard sealed door.
2. Ensure it can be opened from inside quickly.
3. Use magnetic strips, weights, or overlap to improve contact.
4. Do not lock participants inside.

## Phase 5 - Grounding bond

1. Bond lower perimeter mesh with bare copper wire if using a common shield reference.
2. Avoid ground loops.
3. Do not attach to unknown mains ground.
4. Document grounding layout with photos and a diagram.

## Phase 6 - Interior setup

1. Add chair, laptop stand, sensor cable routing, and ventilation.
2. Keep cables away from feet and moving parts.
3. Keep emergency exit clear.
4. Avoid coiling long analog leads near EEG electronics.

## Phase 7 - Testing

Run `testing_protocol.md` before human sessions.
