# Public-safe photos

Place public-safe Box photos here only after review.

Before committing photos:

- remove EXIF and GPS metadata;
- avoid faces unless explicitly consented;
- crop out private addresses, license plates, family items, private documents, and location identifiers;
- avoid showing unsafe wiring or ambiguous electrical setups unless the caption explains the safety status;
- use low-resolution copies when adequate.

Recommended filename pattern:

```text
box_frame_overview_public_safe_001.jpg
box_mesh_seam_public_safe_001.jpg
box_door_flap_public_safe_001.jpg
box_interior_cable_routing_public_safe_001.jpg
```
