# Synthetic demo

Use this folder for toy data that can be committed publicly.

Allowed:

```text
synthetic feature CSVs
synthetic XDF-like test tables
synthetic event logs
small generated demo videos with no copyrighted material
```

Not allowed:

```text
real participant raw data without consent
copyrighted movies
private run logs
personal file paths
```

Suggested demo:

```text
1. Generate a 60-second synthetic stimulus.
2. Generate fake theta/gamma/API/respiration features.
3. Generate fake event overlays.
4. Render a MasterSync demo video.
5. Confirm the pipeline works without any private data.
```
