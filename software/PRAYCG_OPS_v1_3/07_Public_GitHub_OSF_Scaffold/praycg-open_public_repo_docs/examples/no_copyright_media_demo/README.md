# No-copyright media demo

Use this folder to document lawful demo stimuli.

Options:

```text
public-domain clips
Creative Commons clips with compatible license
self-created videos
synthetic generated videos
simple geometric demo clips
```

Rules:

- include source/license notes;
- keep a copy of the license or attribution requirements;
- do not include commercial movie clips;
- do not include copyrighted audio;
- avoid showing identifiable people without consent.

Suggested file list:

```text
README.md
source_attribution.md
stimulus_master_demo.mp4  # only if legally redistributable
cue_schedule_demo.json
media_prep_manifest_demo.json
```
