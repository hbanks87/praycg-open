# PRAYCG

PRAYCG is a local-first neuroscience Workbench and a public research library. Use the Workbench to prepare studies, record supported signals and analyze saved recordings.

**[Download Public Workbench 11.13.1](https://github.com/hbanks87/praycg-open/releases/tag/PRAYCG_Workbench_Public_A11.13.1)** · [Install or update](workbench/docs/installation.md) · [Changelog](workbench/CHANGELOG.md)

Download **PRAYCG_Workbench_Public_Alpha_11_13_1.zip** from the release assets. The application source is inside that ZIP. GitHub’s source archives contain the research and documentation tree.
