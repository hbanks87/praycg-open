# Open movie stimulus recipe: Sintel excerpt

Recommended public/open online source: **Sintel** by Blender Foundation / Durian Open Movie Project.

License: Creative Commons Attribution 3.0.

This folder contains a recipe script, not the source video itself. Run it locally to download Sintel from Wikimedia Commons or another official mirror, trim a 3-4.5 minute excerpt, and then run MediaPrep v1.8 on the resulting source clip.

Attribution to include if using Sintel:

```text
Sintel © copyright Blender Foundation | www.sintel.org / durian.blender.org
Licensed under Creative Commons Attribution 3.0 Unported.
This PRAYCG demo uses a transformed excerpt for protocol testing.
```

Why not bundle the full film here: GitHub is not ideal for large media, and the source license requires attribution/credit handling. The OSF package is a better place for generated public-safe demo outputs.
